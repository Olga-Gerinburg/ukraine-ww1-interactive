# Україна в роки Першої світової війни 🇺🇦

Інтерактивний освітній вебзастосунок для вивчення історії України (10 клас). Проєкт створений для гейміфікації навчального процесу, систематизації знань та підготовки до тестувань. 

Застосунок поєднує роботу з історичними картами, хронологією, візуальними джерелами та тестовими завданнями у єдиному зручному інтерфейсі.

## 📌 Основні можливості та структура

Інтерактив складається з 6 тематичних блоків:
1. **Території:** Інтерактивна карта територіальних претензій воюючих країн (з'єднання країн та регіонів).
2. **Битви:** Хронологія та розпізнавання ключових військових операцій за картосхемами.
3. **Фронт:** Drag-and-drop завдання на встановлення змін лінії фронту (1914–1917 рр.).
4. **Поняття та Постаті:** Робота з флеш-картками для вивчення організацій та drag-and-drop ідентифікація історичних діячів.
5. **Шлях УСС:** Комплексний блок про Легіон Українських січових стрільців (відеохроніка, інтерактивна карта бойового шляху, розпізнавання стрілецьких пісень).
6. **Самоперевірка:** Тренувальні тести у форматі ЗНО/НМТ з миттєвою перевіркою та розрахунком відсотка успішності.

## 🛠 Технології
* **HTML5 / CSS3**
* **JavaScript (ES6+)** – власна логіка перевірки завдань, робота з SVG-лініями та Drag-and-Drop API.
* **Tailwind CSS** – адаптивний дизайн та стилізація інтерфейсу.
* **LocalStorage API** – збереження прогресу учня (всі відповіді та відкриті вкладки зберігаються навіть після оновлення сторінки).

## 👨‍🏫 Використання
Проєкт розрахований на використання як під час очних уроків (на інтерактивній дошці) та онлайн-занять, так і для самостійного опрацювання учнями вдома. Усі виконані завдання зберігаються локально в браузері користувача. Для початку роботи заново передбачена функція "Очистити відповіді".
